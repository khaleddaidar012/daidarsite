# دعيدر فلو — Daidar Flow

تطبيق Windows Desktop مستقل، Offline First. اكتملت الواجهة (01–10) والتراخيص والتفعيل (11–16) وإدارة المخزون الأساسية (20–29). المخزون مجاني وفعلي: إضافة وتعديل وتعطيل وبحث في SQLite محلية، دون بيانات تجريبية. باقي الأدوات تعرض قريبًا. المدفوع يتطلب ترخيصًا موقّعًا مطابقًا للجهاز وتتحقق صلاحيته داخل Main. لا مبيعات أو كاشير أو دفع أو Installer نهائي.

## التشغيل من جذر المستودع

المتطلبات: Windows10/11 x64 وNode24 LTS الموصى به، أو Node22.13+ لدعم اختبارات node:sqlite. إصدار Electron الحالي ثابت ومختبر مع SQLite المدمجة.

```powershell
npm --prefix desktop/daidar-flow ci
npm --prefix desktop/daidar-flow start
```

التثبيت الأول يحتاج إنترنت لتنزيل حزم التطوير وElectron. Electron45 قد ينزل runtime في أول تشغيل؛ يمكن تجهيزه مسبقًا عبر `node desktop/daidar-flow/node_modules/electron/install.js`. بعد تجهيز runtime والبناء، ملفات التطبيق والشعار وخط Cairo محلية ولا تحتاج اتصالًا لفتح الواجهة. لا تشغّل نسخة الموقع داخل Electron.

## التحقق

```powershell
npm --prefix desktop/daidar-flow run build
npm --prefix desktop/daidar-flow test
```

الاختبارات تستخدم Electron حقيقيًا بنوافذ مخفية وتغلقه بعدها. يحتاج تشغيل subprocesses مسموحًا على Windows؛ sandbox التطبيق نفسه يبقى فعالًا. تُحفظ صور الواجهة في artifacts/ المحلي المستثنى من Git. لا يفتح اختبار branding المتصفح الخارجي فعلًا؛ يعترض النداء ويتحقق من الرابط.

## البنية والنطاق

- src/main: lifecycle، تحميل محلي عبر daidar://app، تحقق sender للـIPC، رفض التنقل وpopups، سياسة الميزات وفتح روابط محددة فقط.
- src/main/preload.ts: bridge صغيرة typed؛ لا كشف ipcRenderer أو filesystem.
- src/renderer: React RTL، ثمانية كروت ورسائل حالة، CSS متجاوب وخط Cairo محلي.
- src/shared: عقود البيانات و3 ميزات مجانية و5 مدفوعة وقائمة روابط الشركة.
- public: الشعار الأصلي وSplash HTML/CSS.
- tests: policy/native/UI/offline/responsive.

راجع [خطة المهام](../../tasks/README.md) و[تقرير المرحلة الثانية](PHASE2_REPORT.md) و[الهيكل](ARCHITECTURE.md).

## التفعيل والاشتراك

افتح «التفعيل والاشتراك» من الشريط العلوي، انسخ معرف الجهاز وأرسله للإدارة. الإدارة تصدر ملف .dfl أو كودًا موقعًا لمدة شهر/3/6/12. الصق الكود واضغط «تفعيل الكود» أو اختر «استيراد ملف ترخيص». يظهر العميل وتاريخ البداية والانتهاء والعدّاد. لا يؤدي فتح صفحة التفعيل أو تغيير renderer/localStorage إلى منح صلاحية.

المفتاح الخاص للخزنة الإدارية الأصلية في `%LOCALAPPDATA%\DaidarFlowAdmin\signing-private.dpapi`، مشفر لحساب Windows الإداري وخارج Git. لا يُوزع مع العميل ولا يطبع. جذر التحقق العام موجود في src/main/licensing/public-keys.json. من يسحب المصدر من GitHub لا يحصل على صلاحية إصدار تراخيص؛ يحتاج الخزنة الإدارية الأصلية أو تدويرًا صريحًا للمفتاح العام مع تحديث عميل.

أوامر الإصدار والتجديد ونقل الجهاز واستعادة ملف التسليم موثقة في [دليل أداة الإدارة المنفصلة](admin/README.md). لا تعِد أمر init للمشروع المهيأ. عالج ساعة Windows أولًا إذا ظهر clock review. لو تعذر فك التخزين لا تحذف ملفات بيانات العمل؛ تواصل مع الإدارة واستعد ملف التفعيل المحمي من نسخة احتياطية سليمة تحت الحساب نفسه. لا يوجد زر يحذف حالة الحماية لتجاوزها.

لواجهة إدارة الإصدار السهلة، افتح Open-Daidar-License-Admin.cmd من جذر المشروع أو نفّذ `npm --prefix desktop/daidar-flow run admin:ui`. اسم العميل اختياري، ومعرف الجهاز هو أساس ربط الترخيص. الواجهة خاصة بالإدارة ولا تُوزع على العملاء.

## ما بعد هذه المرحلة

المخزون الأساسي أصبح متاحًا؛ باقي وحدات الأعمال18 مؤجلة (المبيعات والكاشير والإضافات)، والمثبت والتوقيع وتقوية الحزم مؤجلة17. لا رابط تنزيل تجاري ولا نشر لهذا التطبيق في Cloudflare Pages.

## المخزون وإضافة المنتجات

اضغط «فتح الأداة» على كارت المخزون، ثم «إضافة منتج». النموذج يفتح داخل الصفحة. أدخل الاسم والسعر والكمية، واختياريًا الباركود والوحدة (قطعة افتراضيًا)، ثم احفظ. السعر صفر مسموح. القطعة/العلبة/الكرتونة بكميات صحيحة؛ كيلوجرام/جرام/لتر بدقة3 أرقام عشرية. السعر حتى رقمين بعد الفاصل، محفوظ كقروش صحيحة. حد المخزون المنخفض5 وحدات حاليًا.

من قائمة ⋯ في الكارت يمكنك التعديل أو الحذف بعد تأكيد. الحذف يعطّل المنتج ويحفظ سجله وباركوده؛ لا يمكن إعادة استعمال باركود المنتج المعطل لمنتج آخر. لا توجد واجهة استعادة المعطلين أو وحدات متعددة الآن. البحث جزئي بالاسم والباركود مع30 عنصرًا لكل صفحة. USB Barcode Scanner الذي يكتب كلوحة مفاتيح يعمل داخل حقل الباركود؛ Enter فيه لا يحفظ تلقائيًا.

القاعدة `inventory.sqlite` في Electron userData (افتراضيًا `%APPDATA%\daidar-flow-desktop` على Windows)، منفصلة عن ملف تفعيل DPAPI. لا تحفظ في مجلد التثبيت أو Git ولا في localStorage. لا تشفّر بيانات المخزون في هذه المرحلة؛ صلاحيات حساب Windows هي الحماية المحلية. اقرأ [معمارية المخزون](INVENTORY.md) و[تقرير التسليم](INVENTORY_REPORT.md). اختبارات `npm --prefix desktop/daidar-flow run test:inventory` تستخدم قواعد مؤقتة فقط؛ `npm --prefix desktop/daidar-flow test` يشمل التراخيص والمخزون.
