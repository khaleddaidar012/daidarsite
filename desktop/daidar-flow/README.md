# دعيدر فلو — Daidar Flow

تطبيق Windows Desktop مستقل، Offline First. اكتملت الواجهة (01–10) والتراخيص والتفعيل (11–16). الكروت تعرض قريبًا؛ وظائف البيع والمخزون لم تنفذ. المدفوع يتطلب ترخيصًا موقّعًا مطابقًا للجهاز وتتحقق صلاحيته داخل Main. لا قاعدة مبيعات ولا دفع ولا Installer نهائي.

## التشغيل من جذر المستودع

المتطلبات: Windows10/11 x64 وNode22.12+ أو Node24 LTS.

```powershell
npm --prefix desktop/daidar-flow ci
npm --prefix desktop/daidar-flow start
```

التثبيت الأول يحتاج إنترنت لتنزيل حزم التطوير وElectron. Electron45 قد ينزل runtime في أول تشغيل؛ يمكن تجهيزه مسبقًا عبر `node desktop/daidar-flow/node_modules/electron/install.js`. بعد تجهيز runtime والبناء، ملفات التطبيق والشعار وخط Cairo محلية ولا تحتاج اتصالًا لفتح الواجهة. لا تشغّل نسخة الموقع داخل Electron.

## التحقق

```powershell
npm --prefix desktop/daidar-flow run build
npm --prefix desktop/daidar-flow test
```

الاختبارات تستخدم Electron حقيقيًا بنوافذ مخفية وتغلقه بعدها. يحتاج تشغيل subprocesses مسموحًا على Windows؛ sandbox التطبيق نفسه يبقى فعالًا. تُحفظ صور الواجهة في artifacts/ المحلي المستثنى من Git. لا يفتح اختبار branding المتصفح الخارجي فعلًا؛ يعترض النداء ويتحقق من الرابط.

## البنية والنطاق

- src/main: lifecycle، تحميل محلي عبر daidar://app، تحقق sender للـIPC، رفض التنقل وpopups، سياسة الميزات وفتح روابط محددة فقط.
- src/main/preload.ts: bridge صغيرة typed؛ لا كشف ipcRenderer أو filesystem.
- src/renderer: React RTL، ثمانية كروت ورسائل حالة، CSS متجاوب وخط Cairo محلي.
- src/shared: عقود البيانات و3 ميزات مجانية و5 مدفوعة وقائمة روابط الشركة.
- public: الشعار الأصلي وSplash HTML/CSS.
- tests: policy/native/UI/offline/responsive.

## التفعيل والاشتراك

افتح «التفعيل والاشتراك» من الشريط العلوي، انسخ معرف الجهاز وأرسله للإدارة. الإدارة تصدر ملف .dfl أو كودًا موقعًا لمدة شهر/3/6/12. الصق الكود واضغط «تفعيل الكود» أو اختر «استيراد ملف ترخيص». يظهر العميل وتاريخ البداية والانتهاء والعدّاد. لا يؤدي فتح صفحة التفعيل أو تغيير renderer/localStorage إلى منح صلاحية.

المفتاح الخاص للخزنة الإدارية الأصلية في `%LOCALAPPDATA%\DaidarFlowAdmin\signing-private.dpapi`، مشفر لحساب Windows الإداري وخارج Git. لا يُوزع مع العميل ولا يطبع. جذر التحقق العام موجود في src/main/licensing/public-keys.json. من يسحب المصدر من GitHub لا يحصل على صلاحية إصدار تراخيص؛ يحتاج الخزنة الإدارية الأصلية أو تدويرًا صريحًا للمفتاح العام مع تحديث عميل.

أوامر الإصدار والتجديد ونقل الجهاز واستعادة ملف التسليم موثقة في [دليل أداة الإدارة المنفصلة](admin/README.md). لا تعِد أمر init للمشروع المهيأ. عالج ساعة Windows أولًا إذا ظهر clock review. لو تعذر فك التخزين لا تحذف ملفات بيانات العمل؛ تواصل مع الإدارة واستعد ملف التفعيل المحمي من نسخة احتياطية سليمة تحت الحساب نفسه. لا يوجد زر يحذف حالة الحماية لتجاوزها.

## ما بعد هذه المرحلة

SQLite ووظائف المخزون والمبيعات والكاشير مؤجلة (18). Installer والتوقيع على ملفات التوزيع وتقوية إعدادات الحزم والتحديثات مؤجلة (17). الحماية الأساسية الحالية تخص التراخيص والتخزين المحلي المحمي؛ التشفير المتقدم لبيانات الأعمال ليس منفذًا. لا رابط تنزيل تجاري ولا نشر لهذا التطبيق في Cloudflare Pages.
