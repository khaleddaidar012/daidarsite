# المخزون الأساسي — قرار المرحلة20–29

نفس Electron/React/TypeScript/Cairo والهوية الحالية، دون تعديل خدمة أو عقود الترخيص. المخزون مجاني؛ IPC مستقل محدد ومتحقق من Main sender، لا SQL أو مسارات ملفات يحددها Renderer. لا مخزون عبر localStorage ولا بيانات seed. node:sqlite متاح ومختبر داخل Electron45 الحالي (Node24.22.1) وNode التطوير؛ لا تبعية native إضافية. API SQLite ما زالت قابلة للتغير بين الإصدارات، لذلك يثبت إصدار Electron وتراجع الترقية مع اختبارات الاستعادة.

SQLite في userData/inventory.sqlite، WAL وsynchronous FULL وforeign_keys وbusy_timeout، migrations داخل transaction مع سجل schema_migrations. جدول products: UUID، اسم، search_name، selling_price قروش INTEGER، quantity أجزاء من ألف INTEGER، وحدة واحدة، barcode TEXT nullable، timestampsUTC، is_active، revision لمنع حفظ نسخة قديمة فوق تعديل أحدث. قيود CHECK وفهرس unique للباركود غير الفارغ يشمل المعطل أيضًا، فلا يعاد استعمال باركود منتج محذوف لسجل مختلف. لا حذف فعلي ولا علاقات مبيعات الآن. إذا أخفق فتح القاعدة يظهر خطأ مخزون مع إعادة المحاولة، دون تعطيل التطبيق أو التراخيص ودون استبدال الملف أو إسقاطه.

سعر صفر مسموح. حد السعر999999999.99 جنيه، كمية999999999.999، بحد عشري2 للعملة و3 للوزن/الحجم، والقطعة/العلبة/الكرتونة صحيحة فقط. التحويل من نص إلى عدد صحيح يتم بدون ضرب float. حد المخزون المنخفض5 وحدات مخزنية، ثابت مركزيًا وقابل للتعديل مستقبلًا. الباركود نص حتى128 حرفًا بدون مسافات، الأصفار البادئة محفوظة. Enter في حقل الباركود لا يرسل النموذج ويبقى التركيز فيه، حتى لا يحفظ suffix مزدوج من ماسح Keyboard HID منتجًا دون قصد. لا POS ولا طباعة/توليد باركود.

قائمة30 عنصرًا لكل صفحة مع count في SQL، بحث جزئي escaped LIKE على الاسم المطبّع والباركود، debounce200ms ورفض نتائج الطلبات القديمة. لا تحميل كامل المنتجات في الواجهة. البحث الجزئي يحتوي فحصًا خطيًا للنصوص؛ يختبر على10 آلاف منتج، وFTS/trigram متاح لاحقًا إذا تضخم الكتالوج. فهارس active/created والباركود، واستعلامات parameterized فقط. عمليات sync قصيرة ومحدودة داخل Main؛ لا عمليات كبيرة غير محدودة من IPC.

توسع الوحدات لاحقًا: يبقى product UUID مرجع المنتج والمخزون بوحدته الأساسية. migration مستقبلية تضيف product_units بمعرف وproduct_id FK وconversion numerator/denominator وselling_price وباركود فريد، وحركات stock_movements بإشارات للمنتج والكمية الأساسية. لا تحويل للوحدة الأساسية بعد وجود عمليات إلا بترحيل واضح، ولا تغيير اسم الوحدة يعني تلقائيًا تحويل الكمية. لا مخطط أو واجهة تحويل متعددة الآن.

المخزون SQLite محلي غير مشفر في هذه المرحلة، تحميه صلاحيات حساب Windows. لا يغيّر الاشتراك أو DPAPI أو التشفير المتقدم. النسخ الاحتياطي والإصدار المثبت ليسا منفذين؛ قبل نقل الجهاز تُغلق النسخة ويؤخذ ملف القاعدة مع WAL/SHM أو backup SQLite سليم بمعرفة الإدارة. لا يُحذف أي ملف تلقائيًا عند خطأ أو انتهاء اشتراك.

مرجع API راجع أثناء التنفيذ: https://nodejs.org/api/sqlite.html .
