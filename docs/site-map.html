منظومة المتاجر الإلكترونية (متجري / Matjari)
صفحة الإعلان، لوحة صاحب المتجر، واجهات المتاجر بـ 5 ثيمات، الروابط المختصرة والدومينات
لاندنج + لوحة التاجر + الواجهات العامة ▾
  • صفحة اللاندنج الإعلانية للمتاجر /{ar|en}/hub/stores
    تعرض مميزات المتجر (24/7، وصول أوسع للعملاء، عرض منتجات أكثر) وزر البدء/التسجيل.
    AR / EN واتساب دعيدر فتح ↗
  • دخول وتسجيل أصحاب المتاجر /{ar|en}/hub/stores/?view=merchant_login
    إنشاء متجر جديد مع اختيار الثيم المبدئي أو ربط حساب متجري بدعيدر هب.
    واتساب دعيدر
  • لوحة تحكم صاحب المتجر /{ar|en}/hub/stores/?view=store_owner
    مساحة إدارة المتجر الكاملة مع شريط الترقية البرتقالي للباقة المجانية.
    صاحب المتجر واتساب دعيدر
    • تبويب: متجري (Overview)
      رابط المتجر المختصر، المعاينة، إحصائيات سريعة، وشرح ربط الدومين الخاص.
    • تبويب: المنتجات
      إضافة وتعديل وحذف المنتجات مع ضغط تلقائي للصور وتحديد التوفر والتصنيف.
    • تبويب: الطلبات
      بحث بالاسم/الهاتف، فلترة بالحالة، وتحديث مراحل الطلب مع إشعارات الطلبات الجديدة.
    • تبويب: بيانات المتجر (Settings)
      رفع/حذف اللوجو، تعديل الاسم والنبذة والعملة ورقم الواتساب (مع تحقق فوري)، واختيار ومعاينة 5 ثيمات.
    • تبويب: الاشتراك والدعم?view=store_owner&tab=subscription
      اختيار الباقة والمزايا والثيم ورفع إيصال التحويل للمراجعة والتفعيل.
    • تبويب: دومين المتجر
      البحث عن دومين وطلب الشراء والربط ومتابعة حالة التفعيل.
  • واجهة المتجر العامة (للزبائن) /s/{slug} https://{custom-domain}/ ?view=storefront&store_id=...
    واجهة التسوق بـ 5 ثيمات (كلاسيك، مينيمال، بوتيك، تقني داكن، كتالوج سريع)، سلة مشتريات، معاينة سريعة، ترتيب المنتجات، وفوتر مخصص — وعزل كامل للوحات الإدارة على الدومين الخاص.
    AR / EN واتساب صاحب المتجر فقط
  • إدارة واستعراض جميع المتاجر ?view=super_admin ?view=explore_stores
    لوحة مشرف المتاجر لتفعيل/إيقاف المتاجر ومراجعة الاشتراكات والتجديدات.
    أدمن فقط

مسارات الـ API الخلفية (Cloudflare Pages Functions)
طبقة الخادم المتصلة بقواعد بيانات Cloudflare D1 (الأدمن، المنظومة، المتاجر)
6 مجموعات API ▾
  • المصادقة الموحدة (Ecosystem SSO) /api/ecosystem/*
    تسجيل الدخول الموحد، Google OIDC، تبادل التوكنات، تسجيل الخروج المشترك، وسجل الاشتراكات.
    ECOSYSTEM_DB
  • واجهات دعيدر هب /api/hub/*
    خدمات العملاء، طلبات الشراء، الأنظمة، الأجهزة المصرّح لها، والملفات.
    ECOSYSTEM_HUB_DB
  • واجهات متجري (Matjari Store API) /api/store/*
    المتاجر، رفع اللوجو (`/logo`)، الثيم (`/theme`)، المنتجات، الطلبات، الدومينات، الروابط المختصرة، والاشتراكات.
    ECOSYSTEM_STORE_DB
  • واجهات لوحة الإدارة /api/admin/*
    مراجعة الطلبات، صلاحيات الموظفين، خزينة كلمات المرور، الإشعارات، واستخدام/نسخ D1.
    أدمن فقط
  • واجهات الموظفين /api/employee/*
    جلسات الموظفين، طلبات تجديد المتاجر، والدردشة الداخلية.
    موظفين
  • واجهات الموقع العام /api/contact /api/projects /api/tracking /api/visit
    رسائل التواصل، بيانات المشاريع، تتبع الطلبات، وإحصائيات الزيارات.
