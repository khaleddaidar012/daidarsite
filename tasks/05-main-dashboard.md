# 05 — الصفحة الرئيسية

الحالة: Done

## الهدف
رأس وهوية وترحيب وشبكة رئيسية وحالة نسخة مجانية.

## المتطلبات
استخدام قائمة الميزات من Main وعرض حالات تحميل/خطأ قابلة لإعادة المحاولة.

## الملفات المتأثرة
desktop/daidar-flow/src/renderer/App.tsx

## خطوات التنفيذ
1. مراجعة المتطلبات والاعتماد على المهمة السابقة.
2. استخدام قائمة الميزات من Main وعرض حالات تحميل/خطأ قابلة لإعادة المحاولة.
3. فحص النتيجة وتسجيل الدليل قبل تحديث الحالة.

## معايير القبول
لا مبيعات أو مخزون أو فواتير تجريبية؛ لا صفحات داخلية.

## دليل التحقق
بناء TypeScript/Vite ناجح واختبار startup.cjs على Electron حقيقي ناجح: ظهور عنوان Dashboard، إغلاق Splash، تعطيل Node وعزل السياق وsandbox. الاختبار يعمل بنافذة مخفية؛ احتاج صلاحية تشغيل subprocesses خارج sandbox الأوامر.
