# 19 — واجهة إصدار التراخيص للإدارة

الحالة: Done

طلب إضافي مستقل بعد مرحلة التراخيص. المهام17–18 ما زالت Pending.

## الهدف
واجهة محلية عربية RTL سهلة لاسم اختياري ومعرف جهاز إلزامي ومدد1/3/6/12. اسم العميل تنظيمي، وربط الترخيص يعتمد على معرف الجهاز فقط.

## التنفيذ
- فصل خدمة الإدارة عن CLI وإعادة استخدامها في Electron مستقل داخل admin/ui؛ العميل لا يستوردها.
- اختيار الخزنة الأصلية دون تغيير مفاتيح أو تهيئة تلقائية؛ حساب Windows نفسه مطلوب.
- إصدار ونسخ وحفظ الملف، سجل وبحث واستعادة كود، ونقل جهاز بنفس تاريخ الانتهاء مع سبب وتأكيد.
- تخزين ترخيص الإصدار داخل خزنة الإدارة قبل نافذة الحفظ؛ إدخال معرف جديد مطلوب بعد النجاح لتقليل الإصدار المكرر.
- تشغيل بنقرتين عبر Open-Daidar-License-Admin.cmd، أو admin:ui. لا Installer أو وظائف أعمال جديدة.

## الملفات
admin/service.ts وlicense-admin.ts وadmin/ui/، build/package scripts، launcher، tests/admin-ui.cjs وlicense-admin.test.cjs، أدلة README.

## التحقق
نجح بناء TypeScript/Vite/Electron، واختبار CLI وDPAPI القديم مع الاسم الاختياري، وفحص عزل dist عن أسرار ومنطق الإدارة. اختبار Electron الفعلي بخزنة ومفتاح مؤقتين أثبت الإصدار بدون اسم واختيار3 أشهر، النسخ والتصدير والسجل وإعادة تحميله، نقل جهاز مع الحفاظ على النهاية، ورفض المدخلات الخاطئة؛ لا overflow عند1220/768/390. صور المعاينة داخل artifacts/ المستثنى من Git. لا تراخيص اختبار أو تغييرات على الخزنة الحقيقية.
